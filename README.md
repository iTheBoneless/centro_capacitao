# Centro de capacitação
Estruturação de Dados

Imaginem que um centro de capacitação profissional oferece cursos de curta duração para profissionais de diferentes áreas. Atualmente, parte das informações é controlada por planilhas separadas, contendo dados de participantes, cursos, turmas e inscrições.Com o crescimento da quantidade de cursos e participantes, e então começaram a surgir dificuldades como; informações repetidas, dificuldade para saber quantos participantes estão inscritos em cada curso, dificuldade para identificar quais cursos possuem maior procura, registros de participantes espalhados em diferentes planilhas, dificuldade para gerar relatórios, avaliações dos cursos armazenadas em arquivos separados e ausência de uma organização central dos dados.

Tendo em vista todas essas problematicas que acontecem com bastante frequencia em instituições atuais, pensei em resolver tudo isso utilizando uma solução em banco de dados.

Propondo uma estrutura que permita armazenar e consultar os principais dados do centro de capacitação.
